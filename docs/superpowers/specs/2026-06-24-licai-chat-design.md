# 理財聊聊（Finance Chat）設計

日期：2026-06-24
作者：iris + Claude

## 目標
在理財小幫手 PWA 新增一個「理財聊聊」分頁，仿照璿璿會考網站的「子瑜聊聊」：
本地知識庫＋關鍵字比對的人設聊天，**零 API、零成本、可離線、純前端**。

## 決定（已與用戶確認）
- **人設角色**：「小幫手」
- **知識庫範圍**：四類全包 — 理財觀念教學 / App 功能導覽 / 傳承稅務常識 / 市場名詞解釋
- **回應引擎**：純關鍵字比對（同子瑜，不接 LLM）

## 放置
- 主檔：`repo/index.html`（手改原始碼）＋ `repo/app.js` ＋ `repo/style.css`
- 新增分頁 `chat`，標題四字「理財聊聊」，加入 `main-nav`
- 分頁內容由 `renderChatSheet()` 動態渲染進 `<main id="content">`（與其他分頁一致）

## 機制（完全照搬子瑜）
1. 本地知識庫 `LICAI_KB`：陣列 `{keys:[關鍵字], reply:'回覆'}`
2. `licaiReply(text)`：精確關鍵字比對 → 主題偵測 fallback → 預設引導語
3. UI：氣泡對話、打字動畫、語音輸入（🎤 zh-TW SpeechRecognition）、重置鈕
4. 配色用 App 既有水藍主題（`--brand-primary` 等），非子瑜粉紅
5. service worker 直接快取，不動後端

## 知識庫內容（~28 則起步）
- 理財觀念：複利、定期定額、ETF、資產配置、風險分散、停利停損、緊急預備金…
- App 導覽：精選基金 / 海外債 / 海外股票 / 資產配置 / 保險 / 小學堂 在哪、怎麼用
- 傳承/稅務：贈與稅免稅額、遺產稅、信託、保單規劃、二代健保…
- 市場名詞：殖利率、本益比、通膨、升降息、殖利率倒掛、Fed…

## 合規
- 教育/工具性質；回覆避免具體買賣建議
- 傳承稅務類附「實際以個案及現行法令為準」
- 沿用既有 footer「資料僅供內部參考，不構成任何投資建議」

## YAGNI（不做）
- 不接 LLM API、不做跨頁對話記憶儲存、不做帳號
