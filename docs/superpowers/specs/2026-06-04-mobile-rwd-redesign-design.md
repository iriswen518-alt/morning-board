# 理財小幫手 — 手機版面改版設計規格（小學堂風格 + 底部分頁列）

- 日期：2026-06-04
- 狀態：已核准設計，待寫實作計畫
- 分支：`feat/mobile-rwd-redesign`

## 1. 背景與目標

理財小幫手 PWA 主要在手機使用，但目前手機體驗不夠友善。使用者明確指出三大痛點：

1. **字太小、太擠** — 基礎字級 14px、行高與內距偏小，閱讀吃力。
2. **切換分頁不方便** — 8 個主分頁藏在頂部下拉鈕（`.nav-toggle` overlay）後，每次切換都要伸手點到螢幕最上方。
3. **表格擠、要橫向滑** — 市場指數表把「指數/收盤/日/本月/今年」5 欄塞進 390px，擁擠。

使用者選擇「大改版（full refresh）」，並指定以現有 **小學堂（academy）版型** 為設計基準。

**目標**：把小學堂的視覺語言套用到整個 app，並針對上述三痛點重構手機版面，桌面版維持可用。

**非目標**：不動資料管線、build 腳本、深色模式、小學堂頁面本身（已是此風格）。不新增資料來源、不改任何數值計算。

## 2. 設計基準：小學堂版型語言

取自 `academy/academy.css`，作為全站設計 token：

| Token | 值 |
|---|---|
| `--brand` 主色 | `#019AB3` |
| `--accent` 輔色 | `#17B5AD` |
| `--deep` 深藍 | `#003D91` |
| `--up` 漲（紅，台股慣例） | `#d62828` |
| `--down` 跌（綠） | `#2a9d8f` |
| 卡片底 `--soft` | `#f5fafb` |
| 卡片框 `--border` | `#e2e8ee` |
| 次要文字 `--muted` | `#6b7785` |
| 卡片圓角 | 12–16px |
| 圖示徽章 | 38–48px 圓形，`linear-gradient(135deg, brand, accent)`，白色 icon，柔和陰影 |

設計特徵：單欄、大量留白、卡片化、每張卡左側圓形漸層圖示徽章 + 粗體標題 + 次要灰色說明、segmented control（pill）作為次分頁。

## 3. 五大改動

### 3.1 漸層 hero 標題列（所有畫面）
- 以 `linear-gradient(135deg, #019AB3 → #17B5AD → #003D91)`、底部圓角（22px）取代現有平面 topbar。
- hero 內含：標題「理財小幫手」、上次更新時間、**搜尋框**（半透明白底、圓角）。
- 尊重 `env(safe-area-inset-top)`（瀏海/動態島）。

### 3.2 放大字級與間距（解決「太小、太擠」）
- 基礎字級 14px → **16px**；行高 1.6。
- 卡片內距加大；所有可點擊元素最小觸控高度 **44px**。
- 區塊標題（sec-title）18px、粗體、深藍，左側漸層色條。

### 3.3 底部分頁列 bottom tab bar（解決「切換不方便」）
- 固定式 iOS 風格底部列，毛玻璃背景，尊重 `env(safe-area-inset-bottom)`。
- **5 格**：`市場` · `新聞` · `基金` · `海外債` · `更多`。
- 「**更多**」點開既有的圖示格 overlay，內含其餘分頁：`海外股票` · `保險` · `資產配置` · `小學堂`。
- **僅手機顯示**（≤ 768px）；桌面（≥ 768px）維持現有頂部 `main-nav`。
- 手機版**移除**原本的頂部下拉鈕 `.nav-toggle`（其功能由底部列 + 更多 overlay 取代）。
- 內容區底部需加 padding（約 84px）避免被底部列遮住；現有的 `home-fab` 回首頁鈕由底部列「市場」取代，移除浮動鈕（手機）。

### 3.4 表格不再擁擠（解決「太擠、要橫向滑」）
- **市場指數**：每個指數改成一張卡 —
  - 上排：指數名稱（左，粗體深藍）＋ 收盤價（右，粗體大字）。
  - 下排：`日 / 本月 / 今年` 三等分，各為「小灰 label + 漲跌幅」，等寬、以細分隔線分隔。紅漲綠跌。
  - 取代現有 `<table class="indices">` 的橫向多欄。**不橫向滑**。
- **基金清單**：改成小學堂風格卡片 —— 左側圓形漸層圖示徽章 + 基金名稱（可換行）+ 幣別/類別 pill badge。
- 其他以 `.indices` / table 呈現的數字區（債市/匯率/美股/台股 等）套用同一「指數卡」格式。
- segmented control（股市/債市/匯率/美股/台股、單筆/定期定額/贏ETF/績效比較）統一改成 pill 樣式。

### 3.5 維持不動
- 深色模式（`prefers-color-scheme: dark`）：新元件需同時定義深色變體。
- 資料管線、build 腳本、小學堂頁面、所有數值與計算邏輯。

## 4. 技術範圍與檔案

實作以 **CSS 改寫為主**，搭配少量 HTML/JS：

- `repo/style.css`（2247 行）— 主要工作量：新增/改寫 hero、字級系統、卡片、segmented、底部列、指數卡、基金卡，以及對應深色模式變體與 ≤768px / ≥768px 斷點。
- `repo/index.html` — 新增底部分頁列 markup；hero 結構調整（搜尋框移入 hero）；手機版隱藏舊 `.nav-toggle`。
- `repo/app.js`（317KB，純 vanilla JS、template-string 渲染）—
  - `switchTab()` 需同步更新底部列 active 狀態（目前只更新 `main-nav`）。
  - 「更多」overlay 開關邏輯（可沿用既有 nav overlay 機制）。
  - 重構表格渲染函式輸出「指數卡 / 基金卡」HTML：主要為 `renderMarketSheet`（行 2008）、`renderThemeIndexBlock`（990）、`renderObondsSheet`（874）、`renderFundsSheet`、`renderUsStocksSheet`（2159）等使用 `.indices` 的區塊。先做市場與基金，其餘沿用同 CSS class 自動受惠。
- 版本字串：`index.html` 內 `style.css?v=` 與 `app.js?v=` 需更新（cache busting）。

## 5. 元件邊界（各自單一職責）

- **hero**：純展示 + 搜尋入口。輸入：標題、更新時間。不含分頁邏輯。
- **bottom-tabbar**：分頁切換 UI。對外介面：點擊 → 呼叫既有 `switchTab(name)`；接收 active tab 名稱以高亮。不知道內容如何渲染。
- **more-overlay**：展示次要分頁格線；點擊 → `switchTab` 後關閉自己。
- **index-card / fund-card**：純展示元件，吃既有資料物件輸出 HTML。換內部不影響呼叫端。

判準：看 class 名即知用途；改 hero 不影響表格；改指數卡不影響底部列。

## 6. 響應式斷點

- `≤ 768px`（手機/平板直式）：hero + 底部列 + 單欄卡片；隱藏頂部 `main-nav` 與 `.nav-toggle`。
- `≥ 768px`（桌面）：隱藏底部列；維持現有頂部 `main-nav`；卡片可多欄（沿用現有 grid）。
- hero 在所有寬度皆顯示。

## 7. 驗證方式

- Playwright 於 390×844（手機）與 1280 寬（桌面）截圖比對改版前後。
- 逐分頁檢查：市場（5 子頁）、新聞、基金（4 子頁）、海外債、海外股票、保險、資產配置、小學堂連結。
- 深色模式截圖。
- 觸控區 ≥ 44px、無橫向捲動、底部列不遮內容、safe-area 正常。
- 既有 Python 測試（`tests/`）不受影響（純前端改動）。

## 8. 風險

- `app.js` 龐大（317KB），表格渲染函式多處共用 `.indices`；先以 CSS 統一受惠、再逐函式調整 markup，降低破壞面。
- 深色模式漏定義新元件 → 需逐元件檢查。
- iOS PWA standalone 的 safe-area 需實機/模擬器確認。
