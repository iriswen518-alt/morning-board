📲 安裝 理財小幫手到手機

把它加到手機主畫面，之後一點圖示就能打開，全螢幕。

✅ 你已經安裝好了，可以直接從主畫面打開。

iPhone（請用 Safari 開啟）

⚠️ 目前不是用 Safari 開啟，請改用 Safari 開這個頁面才能安裝。

  1. 點畫面下方的「分享」圖示
  2. 在選單往下捲動
  3. 點「加入主畫面」
  4. 右上角點「加入」即完成

Android（請用 Chrome 開啟）

✅ 已安裝，可從主畫面打開。

若沒看到「一鍵安裝」按鈕，請手動安裝：

  1. 點右上角選單「⋮」
  2. 點「安裝應用程式」或「加入主畫面」
  3. 點「安裝」即完成
